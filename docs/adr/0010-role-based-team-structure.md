# ADR-0010: Role-based team structure (Founder as Owner; Claude in named, checklisted roles)
Date: 2026-07-27 · Status: Accepted
## Context
Founder (tech-industry CS background) requested proper team organization. Solo+AI building tends to wear only the fun hats (dev/design) and skip QA, compliance, docs. Roles-as-lenses with mandatory checklists counteract this.
## Decision
Adopt docs/TEAM.md: Founder = Owner/CEO + Manual Test Lead + exclusive Evidence Owner; Claude plays PM, Designer, Tech Lead, Developer, QA, DevOps, Data, Compliance-draft, Research-design under a release Definition-of-Done with per-role sign-offs. Child-Development Science Advisor is designated EXTERNAL-HUMAN-ONLY (D2). Decision rights: Founder decides; Claude recommends; inter-role disputes surfaced, never silently resolved.
## Consequences
Every release now carries a role-signed checklist; Founder gains a hands-on QA execution role; independence is honestly located (Founder audits + external humans + frozen numbers), not pretended via role-play.
