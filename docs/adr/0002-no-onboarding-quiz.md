# ADR-0002: No onboarding quiz — learn from behavior
Date: 2026-07-27 · Status: Accepted
## Context
Cold-start options: preference quiz vs. plain first weeks. Founder: quizzes feel "too framed and too binary, no flexibility."
## Decision
Onboarding = two facts (name, birthdate) + one optional free-text note. All personalization is learned from logged behavior. First recommendations are age-appropriate rather than personalized; personalization arrives within the first few rated outings.
## Consequences
Weaker first-48h personalization (accepted); truer signal thereafter (behavior > self-report); onboarding friction near zero. Establishes the product commandment: *watch how people live, don't ask them to describe themselves.*
