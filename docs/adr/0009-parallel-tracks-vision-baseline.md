# ADR-0009: Phase 1 and Phase 2 run in parallel; founder vision = explicit baseline assumptions; gate becomes a binding merge checkpoint
Date: 2026-07-27 · Status: Accepted · Amends: ROADMAP sequencing (Phase 2 entry gate)
## Context
Founder decision: the survey's uncertain timeline must not bottleneck development. Standard risk of gate-first sequencing avoided (idle build capacity) at the cost of the standard risk of parallel sequencing (sunk-cost momentum weakening kill criteria).
## Decision
Development proceeds now, using the founder's vision as the baseline assumption set (A1):
- A1.1 The core pain (sameness / decision fatigue in planning baby outings) is real and frequent beyond the founder.
- A1.2 Developmental-fit matching + honest "not yet" guidance is valued, not merely tolerated.
- A1.3 Near-zero-friction logging will actually be used; the journal-as-side-effect accrues felt value.
- A1.4 Willingness to pay exists at ~$6–8/mo (annual-weighted) for the loop, not the ideas.
All build artifacts derived from these carry the label [ASSUMPTION] until evidence replaces it. The Phase 1 exit gate converts from an entry gate into a **merge checkpoint**: when survey + interviews complete, results are reconciled against A1 in a documented merge review. Thresholds and kill/pivot criteria remain exactly as pre-committed in ROADMAP — unchanged and binding.
## Consequences
Faster progress; risk that momentum biases the merge review — mitigated by: (1) numbers frozen before data, (2) merge review is mandatory and blocking before Phase 3 (no external families on unvalidated assumptions), (3) D3 compliance requirement unchanged, (4) if the merge review triggers kill/pivot criteria, built work is treated as sunk exploration cost, stated in advance so future-us cannot claim surprise.
