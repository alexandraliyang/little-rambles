# ADR-0001: Discovery engine + memory, not a daily planner
Date: 2026-07-27 · Status: Accepted
## Context
Initial framing options: daily planner, discovery tool, or curriculum. Founder (parent of a ~13-month-old) rejected planner framing: days with a baby cannot be pre-scheduled — naps, teeth, weather rule the day.
## Decision
Build a discovery engine with a developmental brain and a memory. It is ready in "found moments" rather than prescribing a schedule. It can be *used* for daily planning but is never designed as a planner.
## Consequences
Home screen = one contextual "right now" card + browsable list beneath (serves both depleted and analytical users). No calendar features. Engagement is opportunistic, not habitual-by-schedule — retention must come from usefulness-on-open, which raises the stakes of the day-3 problem (see risk register).
