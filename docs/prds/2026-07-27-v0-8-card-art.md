# PRD: v0.8 — Illustrated card banners
Target: App 0.8.0 · [ASSUMPTION, ADR-0009] · Origin: founder — text-only cards lack motivational pull.
## Done means
- Per-category illustrated SVG banner (design-system palette, drawn scenes: water/stories/music/animals/nature/sensory/art/playground/science) on: Today hero, Explore cards, Today compact cards, Discover deck cards; idea emoji as focal character so sibling ideas within a category still differ.
- Zero network dependency (inline SVG — always renders in sandbox); zero licensing exposure.
- Image ladder documented: Phase 2 licensed photography; Phase 4 real venue photos via Places (with required attribution) — the actual-place photo is the end-state motivator.
## NOT building
Hotlinked web photos (sandbox-unreliable + licensing discipline); per-idea bespoke art (category-level + emoji focal is enough for now); Memories banners (real user photos live there and must stay the visual star).
