# PRD: v1.0-beta — Installable PWA + activity library expansion
Date: 2026-07-29 · Target: App 1.0.0-beta · Label: [ASSUMPTION, ADR-0009] · Origin: founder — (1) category audit ("are they comprehensive?"), (2) real-life test needs a phone-installable build.
## Pain this kills
Real-life dogfooding is blocked by D1 platform debt: the chat artifact isn't on the home screen, blocks geolocation, and blocks external images. Founder cannot test the product in the moments the product exists for.
## What done means
- Static installable PWA: index.html + bundled app.js (React 18, no build step for deploy) + manifest (standalone display, theme colours) + service worker (offline shell, network-first app.js) + generated icons (192/512/apple-touch).
- Storage migrated from artifact `window.storage` → **IndexedDB** shim with identical async API (escapes localStorage's ~5MB ceiling; photos now safe).
- Activity library: 21 → **45 ideas**, 9 → **16 categories** (added transit, community, food, winter, seasonal, culture, sports); bowling recategorised sensory→sports, theatre science→culture.
- Dev-Map **v1.2.0**: affordances vehicle_watch, snow_play, food_ritual, group_program, seasonal_wonder weighted across all 10 bands; card art for all 16 categories.
- Geolocation (pin) and photo banners become LIVE by virtue of leaving the sandbox.
## Explicitly NOT building
Backend/accounts (data stays on-device this beta) · multi-child · push notifications · Places API · app-store native wrapper.
## Compliance note
D3 obligations are NOT yet triggered: no server, no accounts, no data leaves the device. D3 remains the entry gate for any multi-family/hosted release.
